# homebrew-tap

A Homebrew tap for my command-line tools.

```bash
brew tap nicolas-morisseau/tap
```

The repository is named `homebrew-tap` because that is what Homebrew looks for;
the tap itself is `nicolas-morisseau/tap`.

## What is in here

| Formula | |
| --- | --- |
| [daily-journal](https://github.com/nicolas-morisseau/daily-journal) | Terminal journal with one markdown file per day, kept in git |

```bash
brew install daily-journal
```

## Formula/

Generated output. Each tool's release pipeline commits its own formula here
through GoReleaser, so editing anything under `Formula/` by hand only lasts until
that tool's next release.
